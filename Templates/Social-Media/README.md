- Posts: 1080x1080px (Square), 1080x1350px (Portrait)
- Stories: 1080x1920px (9:16 ratio)
- Reels: 1080x1920px (9:16 ratio)

### Twitter/X

### LinkedIn

## Brand Elements for Social

### Color Overlays
Use 20-30% opacity overlays for text readability:
- Magenta overlay: rgba(255, 0, 255, 0.3)
- Cyan overlay: rgba(0, 255, 255, 0.3)
- Violet overlay: rgba(74, 0, 128, 0.3)

### Text Styles
- Headlines: White, Inter Bold, center-aligned
- Body: White, Inter Regular, left-aligned
- Hashtags: Cyan (#00FFFF)
- Mentions: Magenta (#FF00FF)

### Logo Usage
- Small: Icon-only version (64px min)
- Medium: Logo + wordmark (200px width)
- Large: Full logo with tagline
