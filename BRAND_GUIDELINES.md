# ETHINX Studio - Brand Guidelines v2026

## 🎯 Brand Identity
ETHINX represents innovation, precision, and futuristic technology in decentralized systems.

## 🎨 Color Palette

### Primary Colors
- ETHINX Magenta: #FF00FF (RGB: 255, 0, 255)
- ETHINX Cyan: #00FFFF (RGB: 0, 255, 255)
- Deep Space Violet: #4A0080 (RGB: 74, 0, 128)
- Void Black: #000000
- Cosmic White: #FFFFFF

### Usage Rules
- **Primary**: Magenta + Cyan for main branding
- **Secondary**: Deep Space Violet for dark themes
- **Accents**: Use sparingly for highlights

## 🔤 Typography

### Primary Font Family: Inter
- Headlines: Inter Bold, 32px+
- Body Text: Inter Regular, 16px
- Captions: Inter Light, 14px

### Code Font: JetBrains Mono
- Code snippets: JetBrains Mono Regular, 14px
- Terminal: JetBrains Mono Medium, 13px

## 📐 Logo Usage Guidelines

### Clear Space
- Minimum clearance: 20% of logo width on all sides
- Never place text or elements in clearance zone

### Logo Variations
1. **Primary Logo**: Full color on light/dark backgrounds
2. **Monochrome**: Black/white for print and grayscale
3. **Icon Only**: For favicons and small spaces

### Prohibited Usage
- ❌ Never stretch or distort
- ❌ Never change color ratios
- ❌ Never add effects (drop shadows, glows)
- ❌ Never rotate except in approved animations

## 📁 File Naming Convention

### Structure: [type]_[purpose]_[dimensions]_[variant].[ext]

### Examples:
- logo_primary_full-color_1024x1024.png
- anner_hero_landing_1920x1080_dark.jpg
- icon_app_round_512x512_white.png
- gradient_magenta-cyan_radial_4k.png
- chart_features_matrix_16x9.ai

### Dimensions (Standard Sizes):
- Web: 1920x1080, 1280x720, 800x600
- Social: 1200x630 (Facebook), 1080x1080 (Instagram)
- Print: 300 DPI minimum
- Video: 3840x2160 (4K), 1920x1080 (HD)

## 🎬 Video & Motion Guidelines

### Frame Rates
- Explainer videos: 30 FPS
- UI animations: 60 FPS
- Cinematic: 24 FPS

### Color Space
- Web: sRGB
- Video: Rec.709 for HD, Rec.2020 for 4K HDR
- Print: CMYK

## 📊 Data Visualization

### Chart Colors
- Primary data: Magenta (#FF00FF)
- Secondary data: Cyan (#00FFFF)
- Comparison: Deep Space Violet (#4A0080)
- Background: #0A0A0A (dark), #FAFAFA (light)

### Chart Types
- Line charts for trends over time
- Bar charts for comparisons
- Pie charts for proportions (use sparingly)

## 🔗 Digital Assets

### Social Media
- Profile pictures: 400x400 minimum
- Cover photos: 1500x500 (Twitter), 820x312 (Facebook)
- Story images: 1080x1920

### Website
- Favicon: 32x32, 64x64, 128x128
- Open Graph: 1200x630
- Apple Touch Icon: 180x180

## 📄 Document Templates

### Presentation Slides
- Title slide: Logo top-left, gradient background
- Content slides: Dark theme with cyan highlights
- Thank you slide: Full-bleed image with logo

### Reports & Whitepapers
- Cover: Full brand treatment
- Headers: Magenta accent bars
- Page numbers: Bottom center, cyan
