# ETHINX Brand Asset Checklist

## ✅ Required Assets (Minimum Viable Brand Kit)

### Logos (Priority 1)
- [ ] Primary logo (color) - SVG, PNG (1024x1024)
- [ ] Primary logo (white) - PNG transparent
- [ ] Primary logo (black) - PNG transparent
- [ ] Icon/favicon - ICO, PNG (16x16 to 256x256)
- [ ] App icon - PNG (512x512)
- [ ] Wordmark (horizontal) - SVG, PNG
- [ ] Wordmark (vertical) - SVG, PNG

### Banners (Priority 2)
- [ ] Hero banner (landing page) - 1920x1080, JPG/PNG
- [ ] Presentation title slide - 1920x1080, PNG
- [ ] Social media header - 1500x500, JPG
- [ ] Email header - 600x200, JPG
- [ ] Video thumbnail template - 1280x720, PSD

### Colors & Gradients (Priority 1)
- [ ] Color palette swatches - PNG, ASE, CLR
- [ ] Magenta-Cyan gradient - PSD, PNG (4K)
- [ ] Deep Space Violet gradient - PSD, PNG
- [ ] LUT files for video - .cube (Premiere/Resolve)
- [ ] CSS variables file - .css, .scss

### Typography (Priority 1)
- [ ] Inter font files (OTF/TTF with license)
- [ ] JetBrains Mono font files
- [ ] Font usage examples - PDF
- [ ] Web font embedding instructions

## 🎯 File Format Requirements

### Essential Formats:
- Vector: SVG, AI, EPS
- Raster: PNG (transparent), JPG (high quality)
- Document: PDF (print-ready)
- Video: MP4 (H.264), MOV (ProRes)

### Organization:
1. Use proper naming convention
2. Include source files (PSD, AI)
3. Include exported files (PNG, JPG)
4. Create preview thumbnails
5. Add metadata/copyright

## 🔍 Quality Assurance

For each asset, verify:
- [ ] Colors match brand palette exactly
- [ ] Proper resolution for intended use
- [ ] File size optimized
- [ ] No compression artifacts
- [ ] Correct file format
- [ ] Metadata included
- [ ] License/copyright information
- [ ] Cross-platform compatibility

## 📁 Folder Structure Compliance

Ensure assets are placed in correct folders:
- Logos → Logos_&_Icons/
- Banners → Banners/
- Gradients → Gradients_LUTs/
- Charts → Charts/
- Templates → Templates/
- Fonts → (consider Fonts/ folder)
