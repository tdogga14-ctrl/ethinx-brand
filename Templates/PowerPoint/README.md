# ETHINX PowerPoint Templates

## Master Slides
1. Title Slide
   - ETHINX logo (top-left corner)
   - Magenta-Cyan gradient background
   - White text for contrast

2. Content Slide
   - Dark background (#0A0A0A)
   - Cyan accent bar on left (4px width)
   - Magenta for headings

3. Quote Slide
   - Deep Space Violet background
   - Large, centered text in white
   - Subtle ETHINX watermark

4. Thank You Slide
   - Full-bleed ETHINX background image
   - Contact info in bottom-right
   - Social media icons

## Color Application
- Headers: #FF00FF (Magenta)
- Body text: #FFFFFF (White)
- Accents: #00FFFF (Cyan)
- Backgrounds: #0A0A0A or #4A0080

## Font Sizes
- Title: 44pt
- Headers: 32pt
- Body: 18pt
- Captions: 14pt

## Logo Placement
- Always use provided logo files
- Maintain clear space (20% of width)
- Never stretch or distort
- Use appropriate color variant for background

## Slide Transitions
- Use subtle fades (0.5s duration)
- Avoid flashy animations
- Keep transitions consistent

## Export Settings
- For screen: 1920x1080, 96 DPI
- For print: 300 DPI
- File format: PPTX for editing, PDF for distribution
- Include speaker notes when applicable

## Do's and Don'ts
✅ DO:
- Use brand colors consistently
- Maintain high contrast for readability
- Include ETHINX logo on every slide
- Use provided templates

❌ DON'T:
- Use non-brand fonts
- Add drop shadows or glows to logo
- Use more than 3 colors per slide
- Overcrowd slides with text

## File Naming
Format: presentation_topic_date_version.pptx
Example: ethinx_product_launch_2026-01_v1.2.pptx
